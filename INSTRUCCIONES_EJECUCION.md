# Instrucciones de ejecución
# Requisitos
- Python 3.
- Spyder.
- Librería PyMongo.

# Instalación
Abre la consola de Spyder y ejecuta:

```python
%pip install pymongo
```

# Ejecución
1. Abre el archivo `main.py` en Spyder.
2. Ejecuta el programa con F5.
3. Utiliza el menú para generar, validar, ordenar, exportar y consultar los registros.

# Conexión con MongoDB Atlas
Configura la variable de entorno `MONGODB_URI` en la consola de Spyder con la URI de conexión de MongoDB Atlas.

No publiques contraseñas ni datos privados de conexión.

# Archivos generados
Los archivos TXT, CSV y JSON se guardan en las carpetas correspondientes dentro de `data`.
