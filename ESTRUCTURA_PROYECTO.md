# Estructura del proyecto

El proyecto está organizado de la siguiente manera:

- `main.py`: contiene el programa principal y el menú de opciones.
- `README.md`: describe el proyecto y explica cómo utilizarlo.
- `requirements.txt`: contiene las dependencias necesarias.
- `log.txt`: almacena el registro de las operaciones realizadas.
- `.gitignore`: excluye archivos innecesarios y archivos de entorno.
- `INSTRUCCIONES_EJECUCION.md`: explica cómo instalar y ejecutar el programa.

# Carpeta data

- `data/txt/`: almacena los registros en formato TXT.
- `data/csv/`: almacena los registros en formato CSV.
- `data/json/`: almacena los registros y resultados en formato JSON.

Los archivos de datos se generan al ejecutar las opciones correspondientes del menú principal.
